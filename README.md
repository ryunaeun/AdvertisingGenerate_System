﻿# VideoGenUIForAD

이 프로그램은 Comfy.UI 서버와의 연결을 통해 파이썬으로 작성된 워크플로우 코드를 이용하여 텍스트로 된 프롬프트를 이용해 광고 동영상을 생성하며,
OPEN AI API를 이용하여 영상 생성용 프롬프트 작성을 보조하는 도구를 제공합니다.

### v0.1 - 최초 릴리즈
#### 동작하는 2개의 생성 페이지
##### Prompt_Gen)
- 최초 접속시 보여주는 프롬프트 생성 페이지
- 해당 페이지에서는 원하는 광고 타겟을 선택하고, 이 정보를 바탕으로 API 연결을 통해 프롬프트를 생성 할 수 있음
- Prompt to Video 버튼을 통해 비디오 생성 페이지로 이동
- Example Image 버튼으로 예시 이미지 생성
- Save / Load Prompt 버튼을 통해 프롬프트를 저장하거나 불러오기 가능

##### Video_Gen)
- 프롬프트를 이용하여 비디오를 생성하는 페이지
- 해상도 및 프레임 길이 설정가능 업스케일 기능제공
- Generate Videos 버튼을 통해 영상 생성가능
- 시드를 설정하여 영상 생성이 가능 기본은 랜덤

#### 동작하지 않는 1개의 생성 페이지 
##### Txt2img_Gen)
- 이미지 생성 기능을 대비한 임시 페이지
- UI 기능들은 동작하지만 실제 생성하는 기능은 연결하지 않아 미구현
